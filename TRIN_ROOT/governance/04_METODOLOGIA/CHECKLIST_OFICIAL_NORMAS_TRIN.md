# CHECKLIST OFICIAL DE NORMAS — TRIN

## Normas de trabalho

- [ ] Uma alteração por vez.
- [ ] Nenhuma refatoração por impulso.
- [ ] Nenhum módulo novo sem Etapa Zero.
- [ ] Nenhum código antes da Auditoria Arquitetural.
- [ ] Nenhum módulo congelado sem Auditoria HARD.
- [ ] Nenhuma alteração estrutural sem checkpoint Git.
- [ ] GitHub é o cofre oficial do projeto.
- [ ] Estabilidade antes da velocidade.
- [ ] Conhecimento antes da IA.
- [ ] Se houver conflito entre código e governança, prevalece a governança.

## Proibido

- [ ] Alterar vários módulos simultaneamente sem versão nova.
- [ ] Quebrar módulo homologado.
- [ ] Apagar histórico sem backup.
- [ ] Calibrar com dados falsos como se fossem reais.
- [ ] Criar módulo por impulso.
- [ ] Permitir que um módulo execute função de outro.
- [ ] Tratar checklist como substituto de Auditoria HARD.

## Auditoria HARD

Toda auditoria crítica deve tentar reprovar o módulo.

> No TRIN, elogios não homologam módulos.
> Somente uma Auditoria HARD, conduzida com a intenção de encontrar falhas,
> pode conceder aprovação arquitetural.
