# DA-001 — Bernardo como Persistência Cognitiva Oficial

## Decisão

O Bernardo é a camada oficial de persistência cognitiva do TRIN.

Toda memória validada do sistema deverá passar por ele antes de ser consumida por qualquer módulo de inteligência.

## Fluxo

```text
IA
↓
API do Bernardo
↓
Bernardo
↓
Biblioteca
↓
Resposta
```

## Justificativa

Evita que módulos futuros leiam CSV diretamente, reduz acoplamento, preserva rastreabilidade e permite trocar armazenamento no futuro sem quebrar consumidores.
