# INDICE SISTEMICO GLOBAL TRIN

## Fluxo Geral
Mercado → RTD → Core → Memória → Engine → Governança → Decisão → Painel

## Camadas
- Dados: RTD / Excel
- Processamento: core engines
- Memória: TRINMemoryCore
- Decisão: Fiscal + Bernardo + Zé
- Governança: validação e regras

## Regra principal
Nenhum módulo pode operar fora da governança.
