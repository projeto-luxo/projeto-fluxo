# 🏷️ PADRÃO DE NOMENCLATURA — TRIN

## Arquivos Python

Usar letras minúsculas, sem acento e com underscore.

Exemplo:

```text
ze_do_eucrazio_4_0.py
fiscal_temporal_1_0.py
```

## Documentos Markdown

Usar nome claro, minúsculo e com underscore.

Exemplo:

```text
contrato_ze.md
auditoria_hard.md
```

## Decisões Arquiteturais

```text
DA_001.md
DA_002.md
DA_003.md
```
