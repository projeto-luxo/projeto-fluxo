# 📜 PADRÃO DE MANIFESTOS — TRIN

Todo módulo que gerar artefatos deve gerar manifesto com:

- módulo;
- versão;
- status arquitetural;
- data/hora início;
- data/hora fim;
- duração;
- configuração usada;
- arquivos de origem;
- hashes de origem;
- arquivos de saída;
- hashes de saída;
- alertas;
- erros;
- contrato de saída;
- status de certificação, quando aplicável.
